# IGoLibrary

IGoLibrary 是“我去图书馆”的第三方桌面预约助手，帮助用户查看场馆和座位、预约座位、维持已签到座位，并接收任务提醒。

## 功能介绍

### 账户与场馆

- 支持电脑版微信授权链接和手机微信扫码授权
- 支持从剪贴板读取授权链接，也可以手动填写 Cookie
- 自动读取账号可用场馆，支持预览、绑定、切换和刷新
- 保存登录状态，重新打开程序后可恢复会话
- 显示当前预约、座位、场馆楼层、有效期、签到状态和学习时间

### 座位与收藏

- 查看场馆座位布局、座位状态和可用座位
- 按座位号搜索，隐藏已占用座位
- 收藏多个目标座位
- 登录或刷新收藏时读取公众号 `oftenseat.list` 常用座位，并与本地收藏合并
- 公众号删除常用座位不会删除程序中主动添加的本地收藏
- 使用场馆 ID 和座位 ID 区分座位，不因座位名称相同而误合并

### 今日抢座

- 选择一个或多个目标座位持续监控
- 支持直接预约、先查询空座再预约
- 支持一键随机空座
- 支持极限速度、固定延迟和随机延迟等轮询模式
- 支持定时启动
- 提供轮询次数、请求数、运行时长和实时日志

### 明日预约

- 支持选择明日预约和明日目标座位
- 支持指定座位或随机空座
- 支持定时启动和排队重试
- 可在预约记录中查看或取消明日预约

### 占座守护

- 对已经签到的今日预约执行自动重约
- 支持“到期前”或“指定时间”触发重约
- 到达触发点后取消当前预约，再尝试预约原座位
- 支持刷新频率、重约间隔和指定时间设置
- 预约记录显示当前运行状态和实时日志

### 退座与积分

- 支持手动取消预约；已签到的今日预约会显示为“退座”
- 支持 Windows 每日定时自动退座
- 自动退座会正常结束当天学习记录，具体积分规则以公众号为准
- 支持登录后自动积分签到
- 账户页面提供“积分签到”手动备用按钮
- 首页显示学习时间、排名、单日最长学习时间和积分

### 通知与更新

- Cookie 失效、即将过期、抢座成功和任务失败时显示本地通知
- 支持 Toast 弹窗和提示音
- 支持 SMTP 邮件提醒，并可发送测试邮件
- 程序可检查 GitHub Release 并提示新版本

## 下载

请前往 [Releases](https://github.com/Luofaiz/IGoLibrary/releases/latest) 下载最新版。

Windows 用户可以选择：

- `IGoLibrarySetup.exe`：安装版，适合日常使用
- `IGoLibrary-Windows-x64.zip`：便携版，解压后运行 `IGoLibrary.exe`

## 使用说明

### 1. 完成授权

打开程序的“账户与场馆”页面，使用电脑版微信打开授权入口，或使用手机微信扫描二维码。

授权后复制包含 `code=` 的链接。电脑版微信通常可直接复制页面地址；手机授权后，将链接粘贴回程序。程序会获取并验证 Cookie。

如果授权链接无法使用，可以在“高级：手动填写 Cookie”区域输入 Cookie 后点击“验证有效性”。

Cookie 有有效期。失效后请重新授权；切换账号时，先注销当前账号，再使用新账号登录。

### 2. 绑定场馆

登录成功后，程序会加载账号可用场馆。选择场馆后先预览，确认无误后点击锁定/绑定。绑定后程序会加载座位布局和预约状态。

### 3. 收藏常用座位

登录或刷新座位时，程序会自动读取公众号中的常用座位，并和本地收藏合并。公众号中删除的常用座位不会导致本地收藏丢失。

在座位选择器中可以搜索座位、隐藏已占座位、刷新布局并选择多个座位。保存收藏后，收藏会写入本地数据库；收藏本身不会自动发起预约，仍需在抢座任务中选择目标。

### 4. 开始今日抢座

进入“抢座”页面：

1. 选择“今日预约”。
2. 打开座位选择器，选择目标座位并确认。
3. 选择抢座策略和轮询模式。
4. 可选填定时启动时间。
5. 点击“开始监控”。

不指定座位时，可以直接使用“一键随机空座”。任务运行期间请保持网络连接，并通过实时日志确认状态；完成后点击“停止任务”。

轮询越快，请求越密集，也越容易触发平台限制。出现频率限制或连续错误时，应停止任务并稍后重试。

### 5. 使用明日预约

在“抢座”页面选择“明日预约”，然后选择目标座位、策略和启动时间。明日预约可能需要排队，程序会显示排队和重试状态。预约成功后可在首页或预约记录中查看。

### 6. 开启占座守护

已有今日预约并完成签到后，进入“占座”页面，选择重约触发方式和时间，点击“开始占座”。程序会在触发点取消当前预约，再尝试预约原座位。

取消和重新预约之间存在短暂空窗，原座可能被其他用户预约。请避免同时在微信端操作同一预约，并根据场馆规则谨慎使用。

### 7. 手动退座和每日自动退座

在首页或预约记录中，今日已签到的预约使用“退座”按钮；尚未签到的记录使用“取消预约”。

如需每天自动退座，进入“退座”页面，输入 `HH:mm` 格式的时间并开启开关。Windows 会创建任务计划，即使程序没有保持打开，也会尝试在指定时间恢复登录会话并退座。电脑关机、用户注销、网络不可用或会话过期时无法保证执行成功。

### 8. 积分签到

设置中的“登录后自动积分签到”默认开启。登录或恢复会话时，程序会尝试领取每日积分签到奖励；账户页面的“积分签到”按钮可用于手动操作。签到结果会显示在账户页面，实际奖励和限制以公众号规则为准。

### 9. 设置提醒和更新

在“通知设置”中可开启本地弹窗、提示音或 SMTP 邮件提醒，并使用测试按钮确认配置有效。

程序会检查 GitHub Releases。发现新版本后按提示下载并安装，更新不会主动删除本地设置、收藏和登录数据。

## 本地数据

Windows 用户数据默认保存在：

```text
%LOCALAPPDATA%\IGoLibrary
```

其中包含设置、收藏、日志和会话信息。正常更新或卸载程序不会主动删除这些数据。
